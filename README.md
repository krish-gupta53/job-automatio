# CreatorPilot AI (Hackathon MVP)

FastAPI backend for creator-focused script generation with a self-improving learning loop.

## Features
- Creator profile memory
- Last-5 video performance memory
- Source ingestion (text/web/ocr content)
- Script generation (<= 3 minutes)
- Learning updater from top-performing videos

## Run
```bash
pip install -r postcss.config.mjs
uvicorn main:app --reload
```
